# Python for Analytics – Course Portfolio
## Repository Overview
This repository contains a collection of assignments and exercises  completed as part of a Python for Analytics course focused on applying programming to realistic business problems.

The course emphasized the integration of coding, analytical reasoning, and business communication, mirroring the structure and expectations of an MBA-style analytics course. All work in this repository demonstrates hands-on experience using Python to explore data, build models, visualize insights, and communicate findings to non-technical stakeholders.

## Course Focus & Learning Objectives

- Throughout the course, I developed practical skills to:

- Use Python as an analytical tool to explore, manipulate, and analyze large datasets

- Create and interpret data visualizations to communicate trends, patterns, and insights

- Apply statistical and machine learning techniques for descriptive and predictive analytics

- Translate technical analysis into clear, business-focused insights suitable for decision-makers

## Tools & Technical Environment

- Python for data analysis and modeling

- Google Colab for in-class coding and experimentation

- Jupyter Notebooks / Anaconda for local development

- GitHub for version control and public portfolio presentation

## Key Python libraries used across assignments include:
- pandas, numpy – data manipulation and analysis

- matplotlib, seaborn – data visualization

- scikit-learn, statsmodels – statistical modeling and machine learning
